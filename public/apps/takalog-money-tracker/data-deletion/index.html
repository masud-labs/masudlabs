Data Deletion Instructions

TakaLog Money Tracker

Developer: Masud Labs
Support: masudlabssupport@gmail.com

Pre-Release Documentation Notice

This documentation describes the current data storage and deletion procedures for TakaLog Money Tracker. The app does not provide a separate Masud Labs hosted user account or an automated online account-deletion endpoint.

1. Account and Google Sign-In

TakaLog Money Tracker does not require users to create a separate account with Masud Labs. Google Sign-In is optional and is used only to connect a Google account for Google Drive backup and restore.

The connected Google account details are stored locally in the app's preferences to maintain the connection state.

2. Disconnect Your Google Account

  1. Open TakaLog Money Tracker.
  2. Go to the Backup & Restore screen.
  3. Select the Disconnect option.

Disconnecting removes the locally stored connected-account state and stops the current Google Drive connection. It does not delete backup files already uploaded to Google Drive.

3. Revoke Google Account Authorization

You can also revoke TakaLog's access from your Google Account:

  1. Open your Google Account settings.
  2. Go to the third-party apps and services access section.
  3. Find TakaLog and remove its access.

Revoking Google authorization stops the app's authorized access. It does not automatically delete backup files stored in Google Drive.

Google Account access management: https://myaccount.google.com/connections

4. Delete Google Drive Backup Files

Optional cloud backups are stored as encrypted .tkb files in the user's private Google Drive appDataFolder. Backup files may contain app settings, categories, financial transactions, and lend and borrow records.

To delete cloud backup files:

  1. Keep your Google account connected to TakaLog.
  2. Open the Backup & Restore screen.
  3. Turn off Auto Background Backup.
  4. View the list of available remote backup files.
  5. Delete each backup file using the in-app delete option.
  6. Repeat until the backup list is empty.
  7. Verify that no backup files remain before disconnecting.

Disconnecting your account, signing out, clearing app storage, or uninstalling the app does not delete previously uploaded Google Drive backup files. Delete those files separately while the app still has authorized access.

5. Delete Local App Data

TakaLog stores financial records locally using Room/SQLite and Android DataStore. Local data may include transactions, categories, lend and borrow records, settings, and connected-account state.

To remove local app data:

  1. Open Android Settings on your device.
  2. Go to Apps and select TakaLog Money Tracker.
  3. Open Storage.
  4. Select Clear storage or Clear data.

Alternatively, uninstalling the app removes its private local application data. The app's Android manifest disables Android backup for its application data.

6. Exported Backup Files

If you exported a .tkb backup file using the Android file picker, that file may be stored outside the app's private storage. Clearing app data or uninstalling TakaLog does not necessarily remove such exported files.

Locate and delete exported .tkb files separately using your device's file manager or the storage location you selected.

7. Other Data Storage

TakaLog does not use Firebase or a separate cloud database to synchronize users' financial records. Financial records are stored locally unless the user chooses to create a Google Drive backup.

8. Request Assistance

If you need help understanding the deletion process or have difficulty removing your data, contact the developer:

Email: masudlabssupport@gmail.com

Please do not email financial records, backup files, Google passwords, access tokens, or recovery passphrases.

9. Important Information

Removing local app data and deleting Google Drive backups are separate actions. To remove both, complete the cloud backup deletion steps and the local app data deletion steps described above.
